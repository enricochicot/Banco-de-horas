# 🕒 Banco de Horas - Cálculo de Salário em C++
# 📄 Descrição
Programa simples desenvolvido em C++ com estrutura sequencial, cujo objetivo é calcular o salário de um trabalhador com base na quantidade de horas trabalhadas e no valor da hora.

Este projeto é ideal para iniciantes, pois demonstra conceitos fundamentais de entrada de dados, operações aritméticas, e exibição de resultados utilizando apenas recursos básicos da linguagem.

# ⚙️ Funcionalidades
Solicita ao usuário:

Total de horas trabalhadas

Valor pago por hora

Calcula o salário total (horas × valor por hora)

Exibe o resultado final no console

# 🧠 Lógica do Programa
O usuário informa o número de horas trabalhadas.

Informa também o valor da hora.

O programa calcula o salário total.

O resultado é exibido na tela.

💻 Instalação e Execução
✅ Requisitos
Compilador C++ (como g++)

Editor de código (como Visual Studio Code)

Terminal (CMD, PowerShell ou terminal do próprio VS Code)

# 📥 Compilação
g++ -o banco bancohoras.cpp

Isso irá gerar um executável chamado bancohoras.cpp

# 🎯 Objetivo Educacional
Este projeto tem como finalidade reforçar os seguintes conceitos básicos:

Entrada e saída de dados no console

Tipos numéricos (float, double)

Cálculo simples com operadores aritméticos

Estrutura sequencial (sem desvios ou repetições)
